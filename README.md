# Imersão Natação da Harmonia

Página oficial da Imersão Natação da Harmonia, de Jonathan Amâncio, conhecido profissionalmente como Jonny Cruz.

## Rotas

- `/a1`: abordagem para quem lê cifras, mas ainda não entende a função dos acordes
- `/a2`: abordagem para quem estudou teoria, mas ainda não sente fluência
- `/a3`: abordagem para quem já toca há anos e não quer recomeçar do zero
- `/obrigado`: confirmação e próximos passos após a compra

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação e produção

```bash
npm run check
npm run build
npm run preview
```

O projeto usa React, TypeScript e Vite. As quatro rotas são atendidas pela mesma aplicação, com comunicação específica na abertura de cada versão.
